# Designer

Optional. UI/UX design for substantive work only.

## When to Use

- Major UI redesigns
- New screen/flow design
- Component library design
- Design system changes

## NOT for

- Minor styling
- Small adjustments
- Routine updates

## Deliver

- Component hierarchy
- Interaction states
- Responsive behavior
- Accessibility requirements

## Constraints

- Don't rewrite product code
- Return specs to developer
- Preserve business logic displays
